# neon-2048

A self-contained WebGL2 first-person horror game set in the Backrooms and its basement.

## Play

Open `index.html` in a WebGL2-capable browser. All required image textures and
audio samples are embedded in the page, so no build step is required.

## Controls

- `WASD`: move
- Mouse: look
- `Shift`: run
- `C`: move quietly
- `M`: mask
- `F`: pepper spray
- `G`: feed or secure the cat
- `E`: interact
